## 1. 系统概述

本项目目标为构建直播电商数字化运营管理系统，解决直播电商企业在选品、采购、直播执行、订单、库存、售后和运营复盘中的数据割裂与经验决策问题。系统采用前后端分离三层架构：Vue 展示层负责业务操作界面，Express/TypeScript 业务层负责权限、流程、算法和接口编排，SQL Server 数据层负责业务数据持久化。

核心需求如下：

1. 多角色登录与权限识别，支持管理层、运营、采购、仓储、主播和系统管理员。
2. 商品、SKU、供应商、库存、采购单和采购建议的供应链管理。
3. 直播场次创建、编辑、监控和弹幕/互动数据沉淀。
4. 订单、售后和用户行为数据进入系统并形成运营闭环。
5. 智能选品排名、关联推荐、新品冷启动和数字顾问报告。
6. 运营报表、接口日志和 KPI 指标支撑管理决策。
